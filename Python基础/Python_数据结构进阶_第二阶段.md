# Python 数据结构进阶学习总结（二）

## 一、tuple 元组

### 1. 基本概念

tuple（元组）是一种不可修改的数据结构，可以理解为不能改变的 list。

语法：

``` python
student = ("Alice", 21, "NLP")
```

### 2. tuple 特点

-   有顺序，可以通过索引访问
-   支持切片
-   创建后不能修改元素

示例：

``` python
student = ("Alice", 21, "NLP")

print(student[0])
print(student[0:2])
```

### 3. 单元素 tuple

错误：

``` python
a = (5)
```

正确：

``` python
a = (5,)
```

单元素 tuple 必须带逗号。

### 4. 应用

深度学习中常用于表示数据维度：

``` python
shape = (32, 128)
```

例如 Tensor 的 shape 通常返回 tuple。

# 二、set 集合

## 1. 基本概念

set（集合）是一种无序、不重复的数据结构。

语法：

``` python
numbers = {1, 2, 3}
```

## 2. set 特点

### 自动去重

``` python
numbers = {1,2,2,3,3}
```

结果：

``` text
{1,2,3}
```

### 无固定顺序

集合输出顺序可能变化，这是正常现象。

------------------------------------------------------------------------

## 3. 常用操作

### 添加元素

``` python
s.add(x)
```

### 删除元素

``` python
s.remove(x)
```

### 判断元素存在

``` python
x in s
```

------------------------------------------------------------------------

## 4. list 转 set

常用于快速去重：

``` python
words = ["apple","banana","apple"]

unique_words = set(words)
```

------------------------------------------------------------------------

## 5. NLP 中的应用

统计不同单词数量：

``` python
words = ["I","love","NLP","I"]

len(set(words))
```

用于：

-   构建 vocabulary
-   去除重复 token
-   文本特征统计

------------------------------------------------------------------------

# 三、tuple 与 set 对比

  特点   tuple      set
  ------ ---------- ----------
  符号   ()         {}
  顺序   有         无
  重复   允许       不允许
  修改   不可修改   可以增删
  索引   支持       不支持
