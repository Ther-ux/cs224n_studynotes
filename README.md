## 建议阅读顺序

1. 阅读第一阶段，手写迷你 NLP 流程，练习文本分词和词频统计。
2. 阅读第二阶段，理解元组与集合，尝试用集合统计不同的 token。
3. 继续学习词表构建、NumPy 和 PyTorch，再进入 CS224N 的词向量、神经网络与 Transformer 内容。
